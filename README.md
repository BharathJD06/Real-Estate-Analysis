## 📌 Project Overview
A comprehensive real estate analytics project using Washington State housing data to analyze property market trends, price drivers, and investment opportunities. Python handles data cleaning and statistical modeling while Power BI delivers interactive market dashboards.

## 🗂️ Files
| File | Description |
|------|-------------|
| Cleaning.ipynb | Python data cleaning & preprocessing notebook |
| Real Estate Analysis.pbix | Power BI market analysis dashboard |
| washington_ultimate.csv | Raw Washington State housing dataset |
| Final Dataset for Analysis.csv | Cleaned, analysis-ready dataset |

## 🛠️ Tools & Technologies
- **Python** (Pandas, NumPy, Matplotlib, Seaborn) — Data cleaning & EDA
- **Power BI** — Real estate market dashboards & KPI reporting
- **Jupyter Notebook** — Data pipeline & analysis environment

## 📊 Key Analysis
- Property price distribution by location, size & type
- Price-per-sqft analysis across neighbourhoods
- Correlation analysis: bedrooms, bathrooms, sqft vs. price
- Time-on-market analysis and pricing strategy insights
- Investment ROI potential by property segment
- Geographic heat maps of property values

## 💡 Key Insights
- Location and square footage are the strongest price predictors
- Waterfront properties command a 2–3x price premium
- Identified undervalued neighbourhoods with high appreciation potential
